# kanta-channel-produce

YouTubeチャンネルのプロデュース法をAIスキル化したもの。既存チャンネルの伸長／新規チャンネルの企画の2ルートで、コンセプト定義から初期コンテンツ案（試す3〜4案）の選定まで、人間のヒアリング・承認を挟みながら進める。

映像制作・YouTubeプロデュースのプロ、カンタさん（金の盾3枚・銀の盾8枚）へのヒアリングから体系化した。

## インストール

### Claude Code のスキルとして使う場合

このフォルダごと以下のいずれかに置く:

- 全プロジェクト共通: `~/.claude/skills/kanta-channel-produce/`
- 特定プロジェクトのみ: `<プロジェクト>/.claude/skills/kanta-channel-produce/`

### スラッシュコマンドとして使う場合

`SKILL.md` の中身を `<プロジェクト>/.claude/commands/kanta-channel-produce.md` として保存する（frontmatterの `name:` 行は削除し、`description:` は残す）。

## 使い方

- 既存チャンネル: 「○○チャンネルを伸ばしたい」
- 新規チャンネル: 「△△で新しくチャンネルを作りたい」
- どちらか不明のまま呼ぶと、最初に既存/新規の分岐から聞かれる

途中でヒアリングと選択（コンセプト選び・企画3〜4案選び）を求められるので、対話しながら進めること。最後にチャンネル企画書（Markdown）が出力される。

## 動作要件

- 特別な依存なし。チャンネル分析の精度を上げたい場合は、YouTube Data API等でチャンネルデータを取得できる環境があるとよい（なくてもWeb検索で代替する）
