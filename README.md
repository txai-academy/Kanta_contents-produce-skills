# テレ東AIアカデミー 配布資料

このリポジトリは、テレビ東京コミュニケーションズが運営するYouTubeチャンネル「テレ東AIアカデミー」にて紹介したプロンプトや関連資料の配布を目的とした公式リポジトリです。

※ 最新版は「Releases」よりダウンロードしてご利用ください。

## 配布コンテンツ

### 水溜りボンド・カンタ式 チャンネルプロデューススキル (`kanta-produce-skill.md`)

水溜りボンド・カンタさんへのヒアリングをもとに体系化した企画思考法を、Claude Code / Codex 用のスキルとして使えるようにしたものです。映像制作・YouTubeプロデュースのプロ（金の盾3枚・銀の盾8枚）のノウハウをAIスキル化しています。

本スキルでは、以下の2つのルートに対応し、コンセプト定義から初期コンテンツ案（試す3〜4案）の選定までをサポートします。対話を通じて人間のヒアリング・承認を挟みながら進行し、最終的に「チャンネル企画書（Markdown形式）」を出力します。

- 既存チャンネルの伸長
- 新規チャンネルの企画

## 動作要件

- 特別な依存関係はありません。
- チャンネル分析の精度を上げたい場合は、YouTube Data API等でチャンネルデータを取得できる環境があるとより効果的です（環境がない場合でも、Web検索で代替して動作します）。

## インストール方法

用途に合わせて、以下のいずれかの方法で設定してください。

### A. Claude Code のスキルとして使う場合

配布されているフォルダごと、以下のいずれかのディレクトリに配置してください。

- **全プロジェクト共通:** `~/.claude/skills/kanta-produce-skill/`
- **特定プロジェクトのみ:** `<プロジェクト>/.claude/skills/kanta-produce-skill/`

### B. スラッシュコマンドとして使う場合

配布されている `kanta-produce-skill.md` を、コマンド用のディレクトリに保存して設定します。以下の手順で配置してください。

1. **ファイルの保存**
   `kanta-produce-skill.md` を以下の場所に保存（またはコピー）します。
   保存先: `<プロジェクト>/.claude/commands/kanta-produce-skill.md.md`
2. **ファイル先頭の編集**
   保存したファイルを開き、先頭の設定部分（frontmatter）にある `name:` の行を削除します。（※ `description:` の行はそのまま残してください）

## 使い方

プロンプトから以下のようにお声がけください。

- **既存チャンネルの場合:** 「○○チャンネルを伸ばしたい」
- **新規チャンネルの場合:** 「△△で新しくチャンネルを作りたい」

**補足事項:**
- 既存/新規どちらか不明のまま呼び出した場合は、最初に分岐の質問が提示されます。
- 処理の途中でAIからヒアリングや選択（コンセプト選び・企画案選び）を求められるため、対話しながら進めてください。
